# NOVASHOP
## Sistema de Gestión de E-commerce

### Descripción
NovaShop es un sistema de comercio electrónico diseñado para facilitar la compra y venta de productos mediante una plataforma web.

### Objetivo
Desarrollar una aplicación web que permita administrar productos, usuarios, categorías y pedidos de una tienda virtual.

### Módulos principales
- Gestión de usuarios.
- Gestión de productos.
- Gestión de categorías.
- Carrito de compras.
- Gestión de pedidos.
- Panel administrativo.

### Tecnologías propuestas
- HTML
- CSS
- JavaScript
- PHP
- MySQL
